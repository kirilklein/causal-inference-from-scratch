# Solutions: What if?

1. Among these ten fictional patients, compare average day-12 health if everyone received treatment with average day-12 health if nobody received it.
2. Both can be correct. The ATE compares both potential outcomes for the same ten people. The observed difference compares five treated people with five different untreated people. Here, the treated people tend to be more severely ill.
3. No. We need the patient's health at the same follow-up time without treatment. Recovery, deterioration, or other changes could have occurred without treatment.
4. The average effect is `(0 + 10 + 20) / 3 = 10`. Only one worker has that individual effect. An average does not imply homogeneous effects.
5. The observed difference rises to about +38.67 because the healthier patients now receive treatment. Their untreated prognosis was already better. The script changes treatment assignment, not either potential outcome, so the ATE remains +12.

An adequate explanation identifies the same-population comparison and the unobserved alternative. Saying only “correlation is not causation” does not explain this example.
